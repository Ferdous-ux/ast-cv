# AST-CV

AI-powered resume builder and career platform designed to help users create professional, ATS-friendly resumes.

## 🚀 Overview

AST-CV is a modern career platform that helps users create, improve, analyze, and optimize their resumes for Applicant Tracking Systems (ATS).

The platform combines resume building, ATS analysis, job matching, and AI-powered improvements in one simple experience.

## 🎯 Goals

- Create professional and ATS-friendly resumes.
- Analyze resumes and provide an ATS score.
- Match resumes with job requirements.
- Improve resume content using AI.
- Generate professional PDF resumes.
- Provide a simple and accessible user experience.
